# projeto-passo-certo
Plataforma Passo Certo, projeto para Global Solution 2º semestre 2026


O Passo Certo é uma plataforma web que ensina pessoas idosas a usar serviços públicos digitais por meio de trilhas curtas e de um simulador seguro, onde errar não tem consequência. O objetivo é que a pessoa idosa consiga concluir sozinha tarefas que hoje depende de outra pessoa para fazer, como agendar um atendimento ou identificar uma mensagem de golpe.
